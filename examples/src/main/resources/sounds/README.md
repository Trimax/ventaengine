# Sounds

| File | Source |
|---|---|
| `fire.ogg` | [Fireplace Sound loop](https://opengameart.org/content/fireplace-sound-loop) by PagDev, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Mixed down to mono (OpenAL plays only mono sounds in 3D), the end is crossfaded into the start for a seamless loop |
| `surf-left.ogg`, `surf-right.ogg` | [Beach Ocean Waves](https://opengameart.org/content/beach-ocean-waves) (Alkai Beach, [freesound 18363](https://freesound.org/people/jasinski/sounds/18363/)) by jasinski, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Its four waves are put one after another over a quiet wash into a loop of 40 seconds, and the two channels are two mono files (see `tools/make-surf.sh`) |

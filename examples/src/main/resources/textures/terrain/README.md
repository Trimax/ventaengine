# Terrain textures

Textures of the terrain example, downscaled to 512x512. All of them are from [ambientCG](https://ambientcg.com)
and are licensed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

| Folder | Source |
|---|---|
| `grass` | [Grass004](https://ambientcg.com/view?id=Grass004) |
| `sand` | [Ground054](https://ambientcg.com/view?id=Ground054) |
| `rock` | [Rock051](https://ambientcg.com/view?id=Rock051) |
| `snow` | [Snow010A](https://ambientcg.com/view?id=Snow010A) |

Each folder has the color (`diffuse.jpg`), the OpenGL normal map (`normal.jpg`) and the roughness (`roughness.jpg`).

# Palm

| File | Source |
|---|---|
| `diffuse.png`, `normal.png` and `../../meshes/palm/bend.obj` | [Free palm treeZ v3](https://opengameart.org/content/free-palm-treez-v3) by Nobiax (yughues), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The textures are scaled from 2048 to 1024 pixels and saved as png (the alpha of the diffuse one is the leaves), the model is `palm_bend` (940 triangles, a palm that leans) as it is. The engine scales a mesh to a unit cube, so a palm is as tall as the scale of its object (6 means 6 meters) |
